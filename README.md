# Simple To-Do List App

A clean, responsive, and lightweight to-do list web application built using only HTML, CSS, and vanilla JavaScript. No backend, database, framework, or server required—all data is stored locally in the browser using `localStorage`.

## Features

- **Add Tasks**: Set task description, optional due date, and initial completion status.
- **Task Management**: View all tasks in a neat, organized list.
- **Task Status & Badges**: Mark tasks as done/pending with automatic badges for *Due Today* and *Overdue*.
- **Edit Any Task**: Update task description, due date, and status at any time.
- **Delete with Confirmation**: Safeguard against accidental deletion with a confirmation prompt.
- **Real-Time Search**: Quickly filter tasks by title or due date.
- **Live Counter**: View total, pending, and completed task counts at the top.
- **Friendly Empty State**: Helpful message and icon when the list is clear or search yields no results.
- **Fully Responsive**: Optimized for phones, tablets, and desktops.
- **Offline / Local Storage**: Tasks persist in your browser across sessions.

## Project Structure

```text
├── index.html   # Main markup structure and modals
├── style.css    # Clean, modern, responsive styling
└── script.js    # Task state management and localStorage sync
```

## How to Run

Simply open `index.html` in any web browser. No installation or setup needed!
